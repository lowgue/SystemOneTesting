GPU tests: do fluxo serial ao throughput em lote

Como tornar a avaliação de modelos visuais mais útil numa RTX 3090: servir com vLLM e medir requisições concorrentes sem perder o resultado por imagem.

01 Pesquisa

vLLM aceita visão multimodal

A API de chat compatível com OpenAI recebe imagens. Qwen2.5-VL 3B aparece entre os modelos visuais suportados.

A RTX 3090 tem compute capability 8.6, acima do mínimo documentado pelo vLLM.

02 Problema

O benchmark não saturava a GPU

O runner enviava uma imagem por vez. O caminho antigo do Ollama usava /v1/systemone, uma API customizada que não é a interface OpenAI do vLLM.

03 Resultado principal

Concorrência mensurável, sem perder rastreabilidade

Novo adapter vllm_openai e --concurrency configurável. Cada imagem mantém sua linha de resultado; cada lote registra duração, tamanho e throughput.

Configuração vLLM separada do benchmark local. Ollama fica como perfil legado.
